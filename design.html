Section 04

Slide canvas rhythm.

Pitch decks follow a binary chapter rhythm: dark immersive scenes alternating with light readable scenes. Roughly 60% dark, 40% light, in chapters of 1–3 slides. Same color tokens throughout — only the canvas switches.

Decision rules.

Watch for these mistakes.

Don't

Use #14b8a6 on a light canvas.

Washes out — looks like a faded sticker. Use #0f766e on light.

Don't

Use #0f766e on a dark canvas.

Disappears against black. Use #14b8a6 on dark.

Don't

Use pure white #fff for headlines on dark.

Too harsh. Use #f5f5f7 — softer, calibrated to the system.

Don't

Add a second color besides teal.

No purple, orange, blue, red. Hierarchy collapses if everything competes.

Don't

Color body text with teal.

Teal is for accent only — eyebrows, hero stats, dividers, featured fills.

Don't

Use sans-serif for source citations.

Citations, page numbers, eyebrows, technical data → mono. Always.
